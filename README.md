# SearchHub

Search aggregation website with 19 engines.

## Features
- 19 search engines
- Card-style layout
- Per-card pagination

## Engines
### Academic
- CrossRef
- arXiv

### Medical
- PubMed
- Europe PMC
- ClinicalTrials

### Code
- GitHub
- GitLab

### Encyclopedia
- Wikipedia
- Wikidata
- Wikibooks

### Programming
- Stack Overflow

### General
- DuckDuckGo
- Bing

### Books
- Open Library
- Anna's Archive
